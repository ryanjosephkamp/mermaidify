Privacy

Nothing you draw or type leaves your device. The reader and Mermaid both run in this page, and Mermaid is served from this site, not from another one. The current drawing is kept in this browser's storage so a reload does not lose it; More, then Clear the drawing, empties it. The site uses no cookies, analytics, or third-party requests. A keyboard that reads handwriting is an app of its own, with its own terms.

What it cannot do yet

  • Read handwriting on the drawing. Names are typed after drawing, or written with a pen where the keyboard turns writing into text.
  • Read a photo or a scan of a diagram. It reads strokes as they are drawn, not pictures.
  • Draw kinds of diagram other than flowcharts and state diagrams. In a state diagram, forks and joins, notes, and concurrent regions are not read, and an "o" written where an arrow ends can read as a start or an end.

Report a problem

If a drawing reads wrong, or something here is unclear, open an issue on GitHub. The best report includes the drawing: use More, then Save the drawing, and attach the file.
